# 입법예고 의견 자동 분류

> 작업 중(2026-10-15 시작). 결과가 나오면 첫 표에 의견 수·일치율을 적습니다.

국회입법예고에 시민이 남긴 법안 의견을 분류 기준(코드북)에 따라 LLM으로 자동 분류하고, 사람이 직접 분류한 표본과의 일치율로 품질을 잽니다. 리서치 실무의 자유응답 코딩을 자동화하는 실험입니다.

## 데이터와 개인정보

- 출처: 열린국회정보(진행중·종료된 입법예고), 국회입법예고 — 조회일은 결과와 함께 적습니다
- 의견 작성자 정보는 수집하지 않습니다. 의견 원문은 작성자의 저작물이라 저장소에 올리지 않고 집계 결과만 공개합니다
