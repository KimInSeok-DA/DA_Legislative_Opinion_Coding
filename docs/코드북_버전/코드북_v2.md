# 코드북

- 버전: **v2**(2026-10-17). 구조는 사용자 결정 — 법안 공통 틀, 찬반 별도 칸(의사결정 `1015_03`). v2에서 바뀐 것은 7절
- 대상: 4개 법안의 공개 의견 중 분류 텍스트(제목+본문)가 15자 이상인 의견(`route=llm`). 15자 미만은 읽지 않고 규칙으로 `no_reason`(의사결정 1015_02)
- 사람 검수와 LLM 분류에 같은 코드북을 쓴다
- 예시는 모두 **지어낸 문장**이다. 의견 원문은 옮기지 않는다

## 1. 무엇을 다나

의견 하나에 칸 두 개를 단다.

| 칸 | 값 | 묻는 것 |
|---|---|---|
| 찬반 | `pro` 찬성 · `con` 반대 · `unknown` 불명 | 이 법안이 통과되는 것에 찬성하나 |
| 주제 | 3절 9개 중 **하나** | 찬반의 이유로 주로 무엇을 드나 |

- 글쓴이의 주장이 사실인지, 법안을 바르게 이해했는지는 따지지 않는다. 무엇을 이유로 드는지만 본다
- 욕설·비하 표현이 섞여 있어도 이유가 있으면 그 이유로 단다
- 같은 문안을 몇 글자만 바꿔 낸 의견에는 같은 라벨을 단다

## 2. 찬반

| 값 | 기준 |
|---|---|
| `pro` 찬성 | 법안이 통과되기를 바란다 |
| `con` 반대 | 법안 통과에 반대한다. **국가보안법 폐지법률안에서는 "폐지 반대", "국가보안법을 지켜야"가 반대** |
| `unknown` 불명 | 찬반을 밝히지 않았고 내용으로도 알 수 없다. 찬성과 반대를 함께 말한다(조건부·일부 찬성) |

- 찬반 낱말이 없어도 내용으로 분명하면 그 값을 단다(예: "이 법이 꼭 통과되길 바랍니다" → 찬성, "이 제도로 업계가 한 단계 나아지길 기대합니다" → 찬성)
- 주제 칸과 따로 판단한다. 주제가 `unclear`여도 찬반이 보이면 단다

## 3. 주제 한눈에

| 코드 | 주제 | 한 줄 정의 |
|---|---|---|
| `rights` | 권리·자유 | 법안이 국가 권력으로 국민의 기본권·자유를 줄인다(또는 되찾게 한다) |
| `security` | 안보·체제 | 북한·간첩·외부 세력 때문에 나라의 안보나 체제가 위태로워진다(또는 지켜진다) |
| `burden` | 경제적 부담 | 세금·비용이 늘어 개인·가계·영업의 생활이 어려워진다(또는 나아진다) |
| `fairness` | 공정·형평 | 특정 집단을 차별·표적으로 삼거나 특정 집단에 특혜를 준다, 믿어 온 제도를 갑자기 바꾼다 |
| `effect` | 효과·필요성 | 법안이 필요한가, 목적을 이루나, 사회·시장에 어떤 결과(효과·부작용)를 낳나 |
| `politics` | 정치적 의도 | 법안 내용 대신 발의자·정당·정치 세력의 의도나 성향을 문제 삼는다 |
| `other` | 기타 이유 | 이유는 있지만 위 6개에 맞지 않는다(절차·시기 등) |
| `no_reason` | 이유 없는 찬반 | 찬성이나 반대를 밝혔지만 이유가 없다 |
| `unclear` | 판단 불가 | 무슨 말인지, 이 법안에 대한 말인지 알 수 없다 |

주제 이름에는 방향을 담지 않는다. 같은 `rights`가 반대 의견에서는 "자유를 침해한다", 찬성 의견에서는 "자유를 되찾는다"가 된다. 방향은 찬반 칸에 있다.

## 4. 판단 순서

1. 이 법안에 대한 의견으로 읽을 수 있나? 아니면 `unclear`
   - 다른 법·선거·정당 이야기가 섞여 있으면 **이 법안에 대한 부분만 보고** 2번부터 판단한다. 이 법안에 대한 말이 한 줄뿐이어도 그 줄로 판단하고, 이 법안에 대한 말이 전혀 없을 때만 `unclear`
2. 이유가 있나? 아래 "이유로 치지 않는 것"만 있으면 찬반이 보일 때 `no_reason`, 찬반도 없을 때 `unclear`
3. **내용 이유**(`rights` `security` `burden` `fairness` `effect` `other`)가 하나라도 있으면 `politics`보다 앞선다. `politics`는 이유가 그것뿐일 때만 단다
4. 내용 이유가 둘 이상이면 **가장 많이 말한 이유**(그 이유에 쓴 문장·구절이 가장 많은 것). 비슷하면 **먼저 나온 이유**
   - 구절을 센다. 마지막에 "결국 ~할 것이다"로 모은 결론 문장도 한 구절로만 센다(결론이라고 더 무겁게 보지 않는다)
   - 다른 사람의 사례로만 든 이야기(예: "빚내서 집 산 사람들도 있다")는 글쓴이가 그 이유를 직접 주장할 때만 센다
5. `other`는 다른 주제 어디에도 맞지 않을 때만

### 이유로 치지 않는 것

- 찬반 반복·강조: "절대 반대", "적극 찬성", 같은 말 되풀이
- 법안 이름·내용 되풀이: "○○를 법정단체로 하는 안에 찬성합니다"
- 무엇이 왜 나쁜지·좋은지 없는 평가 낱말: 악법, 나쁜 법, 말이 안 된다, 해롭다, 이상하다, 시대에 맞지 않다, 국민을 무시한다
- 무엇이 왜인지 없이 "필요하다", "환영한다", "지금 법을 그대로 두라"
- 무엇이 어떻게 되는지 없는 막연한 효과 말: "부작용이 많을 것", "역효과가 난다", "나아지길 기대한다", "좋아질 것"(좋다·나쁘다는 방향만 있고 무엇이 좋아지고 나빠지는지 없음)
- 수사적 질문·한탄: "누구 좋으라고 만든 법인가", "정신 차려라", "어이가 없다"
- 감사·응원·욕설만

이유가 되려면 **무엇이**(어떤 권리, 누구의 부담, 어떤 위험·효과) 어떻게 되는지가 들어 있어야 한다. 짧아도 들어 있으면 이유다(예: "세금이 너무 늘어 반대" → `burden`).

### 자주 헷갈리는 것

| 나온 말 | 판단 |
|---|---|
| 자유민주주의·공산화·독재 같은 체제 낱말 | **누가 위협한다고 보는지**로 나눈다. 국가 권력·이 법의 규제가 국민을 누른다 → `rights`. 북한·간첩·외부 세력 때문에 나라가 위험하다 → `security`. 누가 무엇을 위협하는지 없이 법안·발의자에 딱지만 붙인다 → `politics` |
| 통제·규제 강화 | 국민 일반의 자유가 줄어든다 → `rights`. 특정 단체·기관에 권한·이익이 몰린다 → `fairness` |
| 악용·남용 우려 | 누가 무엇에 악용하는지 있으면 그 주제(정권이 비판을 막는 데 → `rights`, 외부 세력이 → `security`). 없으면 `effect` |
| 지금 법·제도 | "지금 법으로 충분하다·문제없다"(바꿀 필요가 없다는 주장) → `effect`. "그대로 두길 바란다"(바람만) → `no_reason` |
| 재산권 | **누가 재산을 빼앗나**로 나눈다. 국가(세금 환수·규제)가 개인 재산을 침해한다 → `rights`. 법안이 사기·범죄 피해로부터 국민 재산을 지켜 준다, "국민 재산을 지켜 주는 법" → `effect`(법안의 효과) |
| 세금 | 글쓴이 자신·가계의 부담 크기·생활 어려움을 직접 말한다 → `burden`. 부담이 부당·불공평하다, 오래 지켜 온 1주택자를 대우해야 한다 → `fairness`. 시장 전체에 미치는 결과(매물·집값·거래가 막힘) → `effect`. 국가가 재산을 가져간다·재산권·거주 이전의 자유를 직접 듦 → `rights`. "세금 때문에"라는 말이 있다고 바로 `burden`으로 보내지 않는다 |
| 결과가 권리 문제 | 법안의 결과로 "아무 말도 못 하게 된다", "비판하면 처벌받는다"를 들면 결과 이야기여도 `rights`(5절 `effect` 정의) |
| 정치적 비난 | 발의자·세력을 "반국가세력", "간첩" 등으로 부르거나 처벌·척결을 요구하면, 법안 내용과 논리가 맞지 않아도 `politics`(이유가 그것뿐일 때). 욕설·한탄만 있으면 `no_reason` |

## 5. 주제별 정의

### `rights` 권리·자유

- **정의**: 법안이 국가 권력으로 국민의 기본권·자유를 침해한다(반대 쪽) 또는 침해된 권리를 되찾게 한다(찬성 쪽)
- **포함**
  - 권리 이름을 들어 침해를 말한다: 표현·언론·알권리, 사상·양심, 재산권, 거주 이전, 직업·영업의 자유
  - 위헌이다, 민주주의·자유에 반한다, 독재·검열·입막음이다(국가 권력이 국민을 누른다는 뜻일 때)
  - 처벌·규제가 지나치다, 기준이 모호해 마음대로 처벌될 수 있다, 비판이 위축된다
- **제외**
  - 위협하는 쪽이 북한·간첩·외부 세력 → `security`
  - 권리 이름 없이 세금·비용 때문에 생활이 어렵다 → `burden`
  - 다른 집단과 비교해 불공평하다 → `fairness`
  - 사기·범죄 피해로부터 국민을 지켜 준다(법안의 효과) → `effect`
- **예시**
  - 반대: "글 한 번 잘못 올렸다고 이렇게 큰 벌금을 물리면 누구도 비판하는 말을 못 합니다"
  - 반대: "오래 살아 온 집의 재산권을 법으로 이렇게 줄여도 됩니까"
  - 찬성: "생각이나 말만으로 처벌받을 수 있는 조항은 없어져야 합니다"

### `security` 안보·체제

- **정의**: 법안 때문에 북한·간첩·외부 세력·반국가 행위로부터 나라의 안보나 자유민주주의 체제가 위태로워진다(반대 쪽) 또는 지켜진다(찬성 쪽)
- **포함**
  - 간첩·반국가 행위를 막거나 처벌할 수단이 사라진다
  - 분단·휴전 상태라 아직 필요하다
  - 외국·외부 세력이 개입하거나 이용한다
  - 북한·간첩·외부 세력 때문에 체제가 흔들린다, 적화된다
  - 국가보안법 폐지안에서 "나라를 지켜야", "자유민주주의를 지켜야"
- **제외**
  - 발의자·정당을 간첩·특정 국가 편이라 부르기만 한다 → `politics`
  - 국가 권력이 국민의 자유를 누른다 → `rights`
- **예시**
  - 반대: "분단된 나라에서 간첩을 처벌할 근거를 없애면 위험합니다"
  - 반대: "외국 세력이 우리 사회에 영향을 넓히기 쉬워집니다"

### `burden` 경제적 부담

- **정의**: 세금·비용이 늘어 개인·가계·자영업의 생활(주거·이사·노후·생계·영업)이 어려워진다(또는 부담이 줄어든다)
- **포함**: 세금이 너무 많다, 세금 때문에 이사·집 바꾸기가 어렵다, 노후 생활비가 줄어든다, 회비·비용이 늘어난다, 수입이 줄어 생계가 어렵다
- **제외**
  - 부담이 부당하다·불공평하다는 데 무게가 있다(투기꾼 취급, 물가 상승분 과세, 징벌적) → `fairness`
  - 개인이 아니라 시장 전체의 결과(매물 감소, 집값 상승, 거래 위축, 임차인에게 떠넘김) → `effect`
  - 재산권·거주 이전의 자유 같은 권리 이름을 든다 → `rights`
- **예시**
  - 반대: "세금이 이렇게 늘면 아이 학교 때문에 집을 옮기려 해도 엄두가 안 납니다"
  - 반대: "매달 내는 회비까지 늘면 작은 사무소는 버티기 어렵습니다"

### `fairness` 공정·형평

- **정의**: 법안이 특정 집단을 차별하거나 표적으로 삼는다, 특정 집단에 특혜·권한을 몰아준다, 믿고 따라온 제도를 갑자기 바꿔 불이익을 준다
- **포함**
  - 실거주 1주택자를 투기 세력처럼 대한다, 특정 집단만 겨냥한 징벌적 과세다
  - 물가 상승분까지 세금을 매기는 건 부당하다
  - 특정 단체·기관에 권한·이익이 몰린다, 소수만 이익을 본다, 독점·가입 강제, 담합·공정 경쟁을 해친다
  - 오래 믿어 온 제도를 갑자기 없앤다(소급·신뢰)
- **제외**
  - 부담의 크기·생활 어려움만 말한다 → `burden`
  - 국민 일반의 자유가 줄어든다 → `rights`
- **예시**
  - 반대: "집 한 채뿐인 사람에게 여러 채 가진 사람과 같은 잣대를 대는 건 공평하지 않습니다"
  - 반대: "협회 한 곳에만 권한을 몰아주는 법으로 보입니다"
  - 반대: "이 제도를 믿고 노후 계획을 세웠는데 갑자기 바꾸면 안 됩니다"

### `effect` 효과·필요성

- **정의**: 법안이 필요한지, 목적을 이루는지, 사회·시장에 어떤 결과(좋은 효과나 부작용)를 낳는지. 결과가 권리·안보·개인 부담·공정 문제이면 그 주제로 가고, 나머지 결과와 필요성이 여기에 온다
- **포함**
  - 찬성 쪽: 피해·사고를 막는다(사기, 허위 정보, 명예훼손), 전문성·신뢰·거래 질서가 좋아진다, 지금 제도로는 부족하다, 지금 법이 다른 법으로 대체되거나 필요 없어졌다(구체적 까닭과 함께)
  - 반대 쪽: 목적을 이루지 못한다, 오히려 역효과가 난다(집값 상승, 매물 감소, 거래 위축, 경제 악영향, 임차인 부담 증가), 지금 법으로 충분하다, 법안의 전제(원인 진단)가 틀렸다, 악용·남용될 우려(누가 무엇에인지 없어도)
- **제외**
  - "필요하다", "효과 없다", "부작용이 걱정된다", "나아지길 기대한다"만 있고 무엇이 왜인지 없다 → `no_reason`
  - 결과가 표현 위축·처벌 공포(말을 못 하게 됨) → `rights`
- **예시**
  - 찬성: "법정단체가 되면 무자격 중개를 걸러 내 거래 사고가 줄 것입니다"
  - 찬성: "퍼진 거짓 소문 때문에 가게 문을 닫는 일도 있으니 무겁게 처벌해야 합니다"
  - 반대: "집을 내놓는 사람이 줄면 오히려 집값이 뛸 겁니다"
  - 반대: "지금 법으로도 충분히 처벌할 수 있는데 새 법이 왜 필요합니까"

### `politics` 정치적 의도

- **정의**: 법안 내용이 무엇을 일으키는지 대신, 법안을 낸 의원·정당·정치 세력의 의도나 성향을 문제 삼는다. **이유가 이것뿐일 때만**
- **포함**: 특정 정당·정권에 유리하게 만든 법이다, 선거·정권 유지용이다, 발의자가 간첩·특정 국가 편이다, 이념 딱지(공산·사회주의·좌파 법)만 붙인다, 발의자를 조사·처벌하라
- **제외**
  - 정치적 표현과 함께 무엇이 침해·위협되는지 말한다 → 그 주제(예: "정권 비판을 막으려는 법" → `rights`)
  - 의도를 묻기만 하는 수사적 질문, 욕설만 → `no_reason`
- **예시**
  - 반대: "특정 정당이 자기들에게 유리하게 만들려는 법입니다"
  - 반대: "법을 낸 사람들의 속셈이 따로 있다고 봅니다"

### `other` 기타 이유

- **정의**: 이유는 있지만 위 6개 어디에도 맞지 않는다
- **포함**: 절차(의견 수렴·공청회 없이 서두른다), 시기(지금은 때가 아니다)
- **예시**: "충분한 공청회도 없이 서둘러 처리하면 안 됩니다"
- 개선용 표본에서 `other`가 10%를 넘으면 주제를 새로 만든다(의사결정 1015_03)

### `no_reason` 이유 없는 찬반

- **정의**: 찬성이나 반대를 밝혔지만 4절의 "이유로 치지 않는 것"만 있다
- **제외**: 짧아도 무엇이 왜인지 있으면 그 주제. 찬반도 없으면 `unclear`
- **예시**
  - "무조건 반대입니다. 이 법은 안 됩니다"
  - "협회를 법정단체로 만드는 법안에 찬성합니다"
  - "한마디로 나쁜 법이라 반대"
- 15자 미만 의견은 읽지 않고 규칙으로 이 라벨이다(1015_02)

### `unclear` 판단 불가

- **정의**: 무슨 말인지 알 수 없다, 이 법안과 관계없는 내용만 있다, 찬반도 이유도 읽을 수 없다. 관계없는 내용이 대부분이어도 이 법안에 대한 말이 한 줄이라도 있으면 그 줄로 판단한다(4절 1번)
- **예시**: "가나다 123", "연금 개혁부터 하세요"(다른 일만 말함)

## 6. 법안별 맥락과 적용

출처: 국회입법예고 법안 페이지 「제안이유 및 주요내용」(조회 2026-10-15, `src/bill_summary.py`). 요지는 제안이유를 줄인 것이고 법안에 대한 평가가 아니다.

### 2214785 국가보안법 폐지법률안 (법제사법위원회)

- 요지: 국가보안법을 폐지한다. 제안이유는 사상·표현·양심의 자유 침해, 형법 등으로 대체 가능, 국제기구의 폐지 권고 등을 든다
- 찬반: "폐지 반대", "국가보안법 유지·수호" = `con`
- 적용
  - 간첩·북한·외부 세력, 휴전 상태, "나라·자유민주주의를 지켜야" → `security`
  - 발의자를 간첩·특정 국가 편이라 부르기만 한다 → `politics`
  - 폐지 찬성 쪽: 사상·표현의 자유 → `rights`, 형법으로 대체할 수 있다·시대가 바뀌어 필요 없다(구체적 까닭과 함께) → `effect`

### 2218197 소득세법 일부개정법률안 (재정경제기획위원회)

- 요지: 1세대1주택 고가주택(양도가액 12억원 초과)의 장기보유 특별공제를 없애고, 1인당 평생 세액감면 한도(2억원)를 두는 세액공제로 바꾼다. 제안이유는 이 공제가 고가주택에 유리해 집값 상승의 원인이 된다는 지적을 든다
- 적용
  - 세금이 늘어 이사·노후·생활이 어렵다 → `burden`
  - 재산권·거주 이전의 자유를 직접 든다 → `rights`
  - 실거주자를 투기 세력 취급, 고가주택만 겨냥, 물가 상승분 과세, 믿어 온 제도를 갑자기 바꿈 → `fairness`
  - 매물 감소·거래 위축·집값 상승·임차인에게 떠넘김, 집값 안정이라는 목적을 못 이룸 → `effect`
  - "사회주의·공산주의 같은 법"만 → `politics`

### 2211676 공인중개사법 일부개정법률안 (국토교통위원회)

- 요지: 한국공인중개사협회에 법정단체 지위를 주고 윤리규정을 만들어 회원을 자율 규제하게 한다. 제안이유는 전세 사기 등 부동산 거래 피해 예방을 든다
- 적용
  - 거래 사고·전세 사기 예방, 전문성·윤리·신뢰 향상, 거래 질서 → `effect`. 이때 "국민 재산권 보호"도 법안의 효과이므로 `effect`
  - 협회에 권한·이익이 몰림, 소수 이익, 가입 강제·독점 → `fairness`
  - 회비·비용 부담 → `burden`
  - "법정단체화 찬성·환영"만 → `no_reason`

### 2208271 정보통신망법 일부개정법률안 (과학기술정보방송통신위원회)

- 요지: 정보통신망 명예훼손의 벌금을 올리고(사실 적시 1억원 이하, 거짓 사실 10억원 이하), 유죄면 위반으로 얻은 이익을 몰수한다. 제안이유는 허위사실 유포·명예훼손으로 얻는 수익이 벌금보다 커 예방 효과가 떨어진다는 점을 든다
- 적용
  - 표현·언론의 자유·알권리 침해, 입막음·검열, 벌금·몰수가 지나침, '허위' 판단 기준이 모호 → `rights`
  - "민주주의·자유에 반한다", "독재법" → `rights`(국가가 표현을 처벌하는 법이므로)
  - 허위 정보·명예훼손 피해를 막아야, 몰수로 범죄를 막는다, 지금 법으로 충분하다 → `effect`
  - 1인 방송 수입이 줄어 생계가 어렵다 → `burden`
