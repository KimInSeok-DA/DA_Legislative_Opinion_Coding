- `src/common.py`(User-Agent·요청 간격 1초·재시도 2회), `src/collect_bills.py`(페이지 응답 캐시 `data/raw/api/`, 있으면 다시 안 부름)

- 의견 목록: `GET /napal/lgsltpa/lgsltpaOpn/list.do?lgsltPaId=…&searchConClosed=0|1`. 페이지 넘김은 같은 주소에 POST(`_csrf`, `pageIndex`, `pageUnit` 최대 100, `sortCol=OPN_NO`, `sortGbn`). 목록 칸은 번호·제목·작성자(마스킹)·의견제출기관·등록일 — **본문은 목록에 없음**
- 의견 본문: `POST /napal/lgsltpa/lgsltpaOpn/findOneLgsltpaOpnById.json`(`lgsltPaId`, `opnNo`, 헤더 `X-CSRF-TOKEN`=목록 페이지 meta `_csrf`, 같은 세션 쿠키). 응답 `result` 필드: `sj`(제목), `cn`(본문), `opnRgDt`, `opbYn`, `delYn`과 **작성자·연락처 필드**(`opnRgrId`, `rgrNm`, `reprNm`, 주소·전화 `lop*`, `commPno*`) → 수집기는 허용 필드만 남기고 나머지는 저장하지 않는다. `delYn=1`은 비공개 의견
- 의견 1건 = 요청 1번 → 1,000건이면 요청 간격만으로 약 17분
- 법안별 의견 수: 사이트 「종료된 입법예고」 목록에 `의견수` 칸과 `sortCol=OPN_CNT` 정렬이 있음(요청 1번으로 상위 법안 확인 가능). 22대 상위는 법안당 3만～12만 건 → 법안 전체 수집이 아니라 **법안 안에서 표본 추출**이 필요
