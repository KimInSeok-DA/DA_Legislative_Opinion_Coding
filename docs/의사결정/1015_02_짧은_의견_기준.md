# 1015_02 짧은 의견 기준(규칙 분류 / LLM 분류 나누기)

- 상태: **결정(2026-10-15, 사용자)** — B. 제목+본문 15자
- 앞 결정: 1015_01 "나" — 짧은 의견은 규칙으로 "이유 없는 찬반", 나머지만 LLM. 기준 20자는 잠정값이었다
- 데이터: 공개 의견 1,843건(4개 법안), `src/clean.py`로 HTML 엔티티·`<br>`을 푼 뒤 잼

## 1. 확인한 사실

- 길이 분포(본문, 공백 하나로 정리 후): 5자 이하 353, 6～10자 219, 11～15자 154, 16～20자 138, 21～30자 191, 31자 이상 788
- 경계 구간(10～29자)을 법안 무작위로 읽어 보니 **길이만으로는 깔끔하게 나뉘지 않는다**. 10～19자에도 짧은 이유가 붙은 의견이 있고(예: "○○가 걱정되어 반대" 꼴), 20자 이상에도 찬반만 반복한 의견이 많다(예: "이 법안에 강력히 반대합니다" 꼴). 예시는 꼴만 보인 지어낸 것
- 제목에 이유가 있고 본문은 짧은 의견이 있다(본문 20자 미만·제목 20자 이상 18건). 제목은 대개 "반대합니다"처럼 본문과 겹친다
- 이유 표지어(때문·위해·므로·우려·침해·해야·부담·악용·위헌·세금·재산·검열 등, 사람이 정한 대략적 목록)가 규칙 쪽에 얼마나 남는지로 기준을 비교했다. **라벨이 아니라 대략적인 지표**다

| 텍스트 | 기준 | LLM 대상 | 규칙(이유 없는 찬반) | 규칙 쪽에 이유 표지어 있는 것 |
|---|---:|---:|---:|---:|
| 본문만 | 10자 | 1,288 | 555 | 6 |
| 본문만 | 15자 | 1,158 | 685 | 11 |
| 본문만 | 20자 | 1,005 | 838 | 40 |
| 제목+본문 | 10자 | 1,420 | 423 | 0 |
| 제목+본문 | **15자** | **1,270** | **573** | **4** |
| 제목+본문 | 20자 | 1,122 | 721 | 21 |

- 제목+본문: 제목이 본문에 이미 들어 있으면 본문만 쓴다
- 본문 20자 이상 1,005건 중 460건(46%)은 이유 표지어가 없다 → **기준을 어디에 두든 LLM 쪽에도 찬반만 있는 의견이 많다**. 코드북에 "이유 없는 찬반" 라벨이 LLM 쪽에도 필요하다

## 2. 선택지

- **A. 본문 20자(잠정값 그대로)**: 규칙 쪽으로 이유 있는 의견이 가장 많이 빠진다(표지어 기준 40건)
- **B. 제목+본문 15자 (권장)**: 규칙 쪽 이유 표지어 4건(573건 중 0.7%). LLM 대상 1,270건(고유 텍스트 1,161)
- **C. 제목+본문 10자**: 규칙 쪽 표지어 0건이지만, LLM 쪽에 "반대합니다"를 몇 번 반복한 수준의 의견 150건이 더 들어간다

## 3. 권장 근거

1. 규칙의 역할은 "판단할 것이 없는 의견만 덜어내기"다. 20자는 이유 있는 의견까지 덜어내고(표지어 40건), 10자는 덜어내는 효과가 작다
2. 제목에만 이유가 있는 의견을 놓치지 않으려면 제목을 합쳐야 한다. 제목이 본문과 겹치면 본문만 써서 길이가 부풀지 않게 한다
3. 1015_01에서 걱정한 "쉬운 사례가 일치율을 부풀림"은 기준만으로 막을 수 없다(20자 이상에도 46%가 표지어 없음). 그래서 일치율은 **전체와 함께 "이유 없는 찬반"을 뺀 라벨들에서도 따로** 보고한다(평가 단계)
4. LLM 비용 차이는 작다(1,005건 → 1,270건). 모델을 정한 뒤 추정치를 먼저 알린다

## 4. 결정

- **B**: 분류 텍스트 = 제목+본문(제목이 본문에 있으면 본문만), 15자 미만은 규칙으로 "이유 없는 찬반", 15자 이상은 LLM. 근거는 3절
- 1015_01의 "20자"를 이 기준으로 바꾼다

## 5. 바꾸는 조건

- 검수 라벨에서 규칙 쪽(기준 미만)을 따로 20건 확인했을 때 이유 있는 의견이 2건 이상이면 기준을 낮춘다
