# 1015_01 법안 선택과 법안 안 표본 추출

- 상태: **결정(2026-10-15, 사용자)** — 법안 B, 짧은 의견 나
- 조회일: 2026-10-15. 출처: 열린국회정보(종료된 입법예고), 국회입법예고

## 1. 확인한 사실

- 국회입법예고 「종료된 입법예고」 목록은 의견 수(`OPN_CNT`) 정렬을 지원한다. 22대 상위 200개 법안의 의견 수는 법안당 15,300～124,970건(`src/site_bill_counts.py`). 상위 200개의 위원회 분포는 법제사법 56, 행정안전 37, 교육 30, 보건복지 23, 국회운영 18, 국방 11 순
- 확인한 10개 법안 모두 `최대 의견 번호 = 목록 전체 건수`, 첫 페이지 100건 안 번호 빈칸 0 → **의견 번호는 1～N 연속**. 의견 번호를 무작위로 뽑으면 목록 페이지를 다 넘기지 않고 법안 안 단순무작위 표본을 얻을 수 있다
- 의견은 대부분 짧다. 무작위 20건(10개 법안)에서 공개 의견 중 20자 미만 비율이 33～89%, 본문 길이 중앙값 5～48자. 같은 본문이 반복되는 비율(가장 많은 본문의 비중)은 11～59%

## 2. 선택지

### 법안
- **A. 의견 수 상위만**: 상위 1～4위. 법제사법·보건복지에 몰리고 짧은 의견 비율이 높은 법안이 섞인다
- **B. 위원회별 1개 + 이유가 담긴 의견 비율 우선 (권장)**: 위원회가 서로 다른 4개 중 20자 미만 비율이 낮은 순 → 국가보안법(법사), 소득세법(재경), 공인중개사법(국토), 정보통신망법(과방)
- **C. B에서 쟁점성이 강한 법안 대신 교육·보건복지 법안**: 초·중등교육법 또는 모자보건법으로 교체. 짧은 의견이 많아 같은 표본 크기에서 주제 분류 대상이 줄어든다

법안은 데이터 기준(의견 수, 위원회, 짧은 의견 비율)으로만 고른다. 법안 내용이나 찬반에 대한 평가는 기준에 넣지 않는다.

### 법안 안 표본
- 법안마다 의견 번호 1～N에서 **무작위 500건**(시드 고정). 4개 법안이면 요청 약 2,000번, 요청 간격 1초로 약 40분
- 예상: 비공개를 빼면 법안당 약 460건, 그중 20자 이상 약 200～310건 → 4개 법안 합계 약 1,000건이 주제 분류 대상

### 짧은 의견 처리
- **가. 전부 LLM 분류**: 코드북에 "이유 없는 찬반 표명"을 두고 모두 분류. 쉬운 사례가 많아 일치율이 부풀려진다
- **나. 20자 미만은 규칙으로 "이유 없는 찬반", 20자 이상만 LLM 분류 (권장)**: 비용이 줄고, 검수 표본(100건)과 일치율은 실제로 판단이 필요한 의견에서 잰다. 20자 기준은 5단계(정제)에서 실제 분포를 보고 확정한다
- 같은 본문 반복은 지우지 않는다(실제로 제출된 의견). 다만 검수 표본은 같은 본문이 두 번 뽑히지 않게 고유 본문에서 뽑는다

### 근거

1. **분류할 내용이 있는 의견이 많은 법안을 고른다.** 이 프로젝트가 재려는 것은 "의견이 어떤 이유·주제로 나뉘는가"다. 찬반만 밝힌 짧은 의견은 주제 정보가 없다. 후보 6개 중 20자 미만 비율이 낮은 4개(32～55%)는 같은 500건에서 주제 분류 대상이 약 200～310건 나오지만, 교육·보건복지 법안(62～65%, 중앙값 9자)은 약 160～175건에 그친다
2. **위원회를 하나씩 나눈다.** 상위 법안은 법제사법·보건복지에 몰려 있다(상위 200개 중 79개). 위원회가 다르면 정책 분야(형사·안보, 세금, 부동산 거래, 정보통신)가 달라서, 같은 코드북 틀이 분야가 달라도 통하는지 볼 수 있다
3. **의견 수만으로 고르지 않는다(A를 고르지 않은 이유).** 상위 1～4위는 법제사법 2개·보건복지 2개이고 그중 보건복지 법안은 짧은 의견이 65% 안팎이다. 의견 수가 많다고 분석할 내용이 많은 것은 아니다
4. **쟁점성으로 빼지 않는다(C를 고르지 않은 이유).** 법안을 고르는 기준은 데이터(의견 수·위원회·짧은 의견 비율)뿐이다. 쟁점성을 기준으로 넣으면 그것 자체가 법안에 대한 판단이 된다. 결과는 "의견이 어떤 주제로 나뉘는가"까지만 쓰고 법안·찬반에 대한 평가는 쓰지 않는다
5. **법안당 500건 무작위.** 의견 번호가 1～N으로 이어져 있어 번호 무작위 추출이 곧 법안 안 단순무작위 표본이다. 500건이면 법안별 주제 비율의 오차가 공개 의견 기준 최대 약 ±4.6%p(95%)이고, 수집은 요청 간격 1초로 4개 법안 약 40분이라 하루 안에 끝난다
6. **짧은 의견은 규칙으로(가를 고르지 않은 이유).** 20자 미만 의견까지 LLM에 넣으면 쉬운 사례가 일치율을 끌어올려 품질을 실제보다 좋게 보이게 한다. 판단이 필요한 의견만으로 일치율을 재야 리서치 품질 지표로 의미가 있다. LLM 호출도 30～55% 줄어든다. 규칙은 "글자 수 20 미만"이라 면접에서 그대로 설명할 수 있다

### 감수하는 한계

- 짧은 의견 비율이 낮은 법안을 골랐으므로 결과를 입법예고 의견 전체의 경향으로 일반화하지 않는다(법안 4개 안에서의 분포)
- 20자 기준은 60건 표본에서 정한 잠정값이다. 20자 미만에도 이유가 있는 의견, 20자 이상에도 찬반만 있는 의견이 있을 수 있다 → 5단계에서 실제 분포를 보고 확정하고, 확정 근거를 이 문서 결과란에 적는다

## 4. 바꾸는 조건

- 500건 수집 후 20자 이상 의견이 법안당 150건 미만이면 그 법안만 표본을 늘리거나 다음 순위 법안으로 바꾼다
