# 1016_01 분류 모델과 호출 방법

- 상태: **결정(2026-10-16, 사용자)** — Claude Code 명령줄(`claude -p`) + Sonnet
- 앞 결정: 1015_04(개선용 50 / 평가용 50)

## 1. 확인한 사실

- OpenAI API: 공식 가격표 확인, 키의 모델 목록에 gpt-5-mini·nano 등 있음. 첫 호출이 HTTP 429 `insufficient_quota`(크레딧 없음). 사용자는 추가 결제를 원하지 않음
- Gemini API 무료 등급: 공식 요금 페이지에 무료 등급 내용은 "Content used to improve our products"라고 적혀 있음. 분당·하루 한도는 AI Studio에서만 보임
- Claude Code 명령줄(`claude -p`): 사용자의 Claude 구독 안에서 돌아 추가 결제 없음. `--json-schema`로 출력 형식 강제, `--tools ""`로 도구 끔, 결과 JSON에 토큰 수와 API 정가 환산액이 나옴
- 표본 100건, 코드북 v1, 개선용 50건 일치율(평가용은 보지 않음, 작업일지 10-16)

| 지표(개선용 50) | Haiku 정확도 / κ | Sonnet 정확도 / κ |
|---|---|---|
| 찬반 | 0.98 / 0.94 | 0.98 / 0.94 |
| 주제 | 0.72 / 0.65 | 0.76 / 0.70 |
| 주제(사람 `no_reason` 뺀 38건) | 0.68 / 0.59 | 0.71 / 0.62 |
| 이유 있음·없음 | 0.90 / 0.73 | 0.96 / 0.89 |

- 정가 환산 100건: Haiku $0.05, Sonnet $0.74. 둘 다 4개 동시 실행으로 약 3분

## 2. 선택지

- 호출: A. `claude -p`(구독 안) / B. Gemini 무료 등급 / C. OpenAI 유료
- 모델: Haiku / Sonnet

## 3. 결정과 근거

- **A**: 추가 결제 없음, 새 키 불필요, 의견 원문(작성자의 저작물)을 학습에 쓰는 조건을 피함
- **Sonnet**: 이유 있음·없음 판단이 50건 중 3건 더 맞음. 주제 정확도 차이(2건)는 우연과 구분되지 않음. 대신 구독 사용량이 더 든다(전체 1,161건 정가 환산 약 $8.5)
- 모델은 **개선용 50건만** 보고 골랐다. 평가용은 코드북 v1·v2 비교 때 처음 연다

## 4. 감수하는 것

- 비용은 실제 청구가 아니라 정가 환산액으로 기록한다
- 명령줄 버전·모델 갱신으로 같은 결과가 다시 나오지 않을 수 있다 → 결과 파일에 실제 모델 이름(`claude-sonnet-5-5`)을 남긴다

## 5. 바꾸는 조건

- 구독 사용 한도에 걸려 전체 분류가 막히면 Haiku로 바꾼다(개선용 일치율 차이가 작음)
